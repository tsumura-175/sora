# 選定画像

クライアント提供画像から、`access/`、`staff/`、`news/`を除くページ用に選定した画像です。

## ディレクトリ構成

- `selection-map.csv`: 使用ページ、用途、元ファイル名、新ファイル名の対応表
- `originals/<page>/`: 元画像を変更せず、新しい名前でコピーしたJPEG
- `web/<page>/*.webp`: 長辺1600px以内のWeb用画像
- `web/<page>/*-1024.webp`: 長辺1024px以内のWeb用画像

OGP画像のみ、SNS表示向けに中央トリミングし、1200×630pxと1024×538pxで出力しています。

## 運用上の注意

- 元画像は `02_頂いた画像一覧` に残しており、変更していません。
- `about/about-tomizawa` は、公開前に富澤様ご本人の写真であることを確認してください。
- `originals/` は確認・再加工用です。公開時は原則として `web/` のWebP画像を使用してください。
- HTMLやテンプレートへの画像差し替えは、この選定作業には含めていません。
